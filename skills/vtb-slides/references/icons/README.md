# Каталог векторных иконок ВТБ

4 354 векторные иконки из фирменного набора `vtb_icons.pptx`: 23 категории, у каждой два стиля.
- `o-…` — контурные (outline): основной стиль для иконок на белом фоне.
- `g-…` — залитые (glyph): для плашек и акцентов.

На одном слайде используйте только один стиль: правило набора «Иконки не дерутся».

**Как выбрать иконку.** Откройте лист нужной категории и найдите иконку; номер написан под ней. ID собирается так: `<стиль>-<категория>-<номер>`, например `g-finance-012`.

**Как вставить.** Вызовите `d.icon(s, "g-finance-012", x, y, size=0.5, color="navy")` или передайте `"icon": "g-finance-012"` в любой компонент. Иконка вставляется вектором: её можно перекрасить и править в PowerPoint. Цвет — `navy`, `cyan`, `white`, `gray` или HEX.

Часть элементов исходного набора — фрагменты составных значков (например, половина значка файла). Выбирайте по картинке только целые иконки.
