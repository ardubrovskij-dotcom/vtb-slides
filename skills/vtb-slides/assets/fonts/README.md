# Шрифты VTB Group

Положите сюда файлы шрифтов VTB Group (`VTB45.otf` … `VTB97.otf`, `VTBGroupUI-*.otf`) из корпоративного дистрибутива. Шрифты лицензированы ParaType для Банка ВТБ, поэтому в публичный репозиторий не входят (папка в `.gitignore`).

Когда файлы лежат здесь:
- `vtb.py` считает размеры текста по метрикам VTB Group, и подгонка становится точной;
- `scripts/install_fonts.sh` ставит их в систему, чтобы LibreOffice рендерил превью настоящим шрифтом.

Соответствие начертаний и имён в теме шаблона:

| Файл | Имя в системе | Где используется |
|---|---|---|
| VTB55.otf | VTB Group Book | основной текст (minor font темы) |
| VTB65.otf | VTB Group Demi Bold | заголовки и выделение (major font темы) |
| VTB45 / VTB75 / VTB95 | Light / Bold / Extra Bold | доступны для ручного использования |
| VTB47/57/67/77/97 | VTB Group Cond … | узкие начертания (заголовок титула в шаблоне) |
| VTBGroupUI-* | VTB Group UI … | интерфейсный вариант, в слайдах не нужен |

На ПК, где будут показывать презентацию, шрифты тоже нужно установить (Windows: правый клик по файлу → «Установить для всех пользователей»). Без них PowerPoint подставит замену; для внешней рассылки собирайте с `"font_mode": "safe"` (Arial).
